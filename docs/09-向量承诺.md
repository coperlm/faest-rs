# 向量承诺（Vector Commitment）

## 🎯 什么是向量承诺？

**向量承诺**允许你承诺一个向量，之后可以选择性地打开某些位置，而不泄露其他位置的信息。

## 📦 类比理解

想象一个**带编号的储物柜**：

```
┌─────┬─────┬─────┬─────┐
│  1  │  2  │  3  │  4  │  → 储物柜（承诺）
├─────┼─────┼─────┼─────┤
│ 🍎  │ 🍊  │ 🍌  │ 🍇  │  → 物品（数据）
└─────┴─────┴─────┴─────┘

特性：
✓ 锁上后别人看不到里面是什么
✓ 可以选择打开某一个柜子
✓ 不能偷偷更换里面的东西
```

## 🏗️ GGM 树结构

代码使用 **GGM（Goldreich-Goldwasser-Micali）树**：

```
                根种子
               /      \
            L           R
          /   \       /   \
        LL    LR     RL    RR     ← 4个叶子节点
```

### 伪随机生成器（PRG）

```rust
// 从一个种子生成两个子种子
trait Prg {
    fn gen(&mut self, seed: Seed) -> (Seed, Seed);
}

// 使用 AES-CTR 模式
pub struct Aes128CtrLdPrg;
```

### 扩展到 N 个值

```rust
// 从根种子展开整个树
fn expand_tree(root_seed: Seed, depth: usize) -> Vec<Seed> {
    // depth=3: 生成 2^3=8 个叶子
    let mut leaves = vec![root_seed];
    
    for _ in 0..depth {
        let mut new_leaves = Vec::new();
        for seed in leaves {
            let (left, right) = prg.gen(seed);
            new_leaves.push(left);
            new_leaves.push(right);
        }
        leaves = new_leaves;
    }
    leaves
}
```

## 🔐 承诺方案

### 结构定义

```rust
pub struct GgmVecCom<Block, Prg, H, Compress> {
    seeds: Vec<Block>,           // 种子
    hasher: H,                   // 哈希函数
    commitment: Output<H>,       // 承诺值
    _phantom: PhantomData<...>,
}
```

### 三个阶段

#### 1. 初始化
```rust
fn new(length: usize) -> Self {
    // length 是要承诺的向量长度
    let depth = log2(length);
    ...
}
```

#### 2. 承诺
```rust
fn commit(&mut self, values: &[Block]) -> Commitment {
    // 1. 生成随机根种子
    let root_seed = random_seed();
    
    // 2. 展开树得到叶子种子
    let leaf_seeds = expand_tree(root_seed, depth);
    
    // 3. 叶子种子 XOR 实际值
    for i in 0..values.len() {
        leaf_seeds[i] ^= values[i];
    }
    
    // 4. 哈希整个树
    let commitment = hash_tree(&leaf_seeds);
    
    commitment
}
```

#### 3. 打开（去承诺）
```rust
fn decommit(&self, indices: &[usize]) -> Decommitment {
    // 只透露必要的中间节点
    let mut revealed_nodes = Vec::new();
    
    for &index in indices {
        let path = get_path_to_leaf(index);
        revealed_nodes.extend(minimal_nodes(path));
    }
    
    Decommitment { nodes: revealed_nodes }
}
```

## 💡 关键技巧：最小揭示

假设打开位置 2 和 3：

```
              根
            /    \
          L       R       ← 只需揭示 R
        /  \     / \
      LL   LR  RL  RR
      ↑    ↑
     位2  位3
     
需要揭示：R（右子树根）+ LL和LR的父节点路径
```

## 📊 性能特点

| 操作 | 时间复杂度 | 空间 |
|-----|-----------|------|
| 承诺 | O(n) | O(n) |
| 打开 k 个 | O(k log n) | O(k log n) |
| 验证 | O(k log n) | - |

## 💻 简化示例

```rust
// 承诺 4 个值
let values = vec![
    Block128([1, 2, 3, ...]),
    Block128([4, 5, 6, ...]),
    Block128([7, 8, 9, ...]),
    Block128([10, 11, 12, ...]),
];

let mut vc = GgmVecCom::new(4);

// 生成承诺
let commitment = vc.commit(&values);

// 打开位置 1 和 3
let decommitment = vc.decommit(&[1, 3]);

// 验证者检查
let is_valid = verify(
    commitment,
    &[values[1], values[3]],
    &[1, 3],
    decommitment
);
```

## 🔗 与 VOLE 的关系

```
VOLE 需要承诺多个随机值
        ↓
使用向量承诺批量承诺
        ↓
打开时只揭示需要的部分
        ↓
保持其他值的隐私性
```
