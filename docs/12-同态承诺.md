# 同态承诺

## 🎯 什么是同态？

**同态**：支持在承诺上直接运算。

```
承诺(a) + 承诺(b) = 承诺(a + b)
```

## 🏗️ HomCom 结构

基于 VOLE-in-the-Head 构建：

```rust
pub struct HomCom128SenderFromVitH<VitHS> {
    vith_sender: VitHS,  // VOLE 发送方
}

pub struct HomCom128ReceiverFromVitH<VitHR> {
    vith_receiver: VitHR,  // VOLE 接收方
}
```

## 🔐 承诺比特

```rust
fn commit_to_bits(&mut self, bits: GF2Vector) 
    -> (Vec<Tag>, Commitment) 
{
    // 1. 用 VOLE 承诺比特向量
    let commitment = self.vith_sender.commit_message(bits);
    
    // 2. 获取输出矩阵 V
    let (_, V) = self.vith_sender.get_output();
    
    // 3. 每行转换为一个 GF(2^128) 标签
    let tags: Vec<GF2p128> = V
        .axis_iter(Axis(0))
        .map(|row| GF2p8::convert_to_gf2p128(row))
        .collect();
    
    (tags, commitment)
}
```

## 🏷️ 标签（Tag）

```rust
type Tag = GF2p128;

// 标签用于快速验证
// 不需要打开整个承诺
```

## 🔄 选择和传输

```rust
// 接收方选择一个挑战
fn choose(&mut self) -> Choice {
    let choice = self.vith_receiver.generate_final_challenge();
    choice
}

// 发送方响应
fn transfer(&mut self, choice: Choice) -> Decommitment {
    self.vith_sender.decommit(choice)
}
```

## 📊 为什么叫"同态"？

```
比特: b1, b2, b3
承诺: C1, C2, C3
标签: T1, T2, T3

性质：
T1 + T2 = 标签(b1 XOR b2)

这是同态性！
```

## 💡 与普通承诺的区别

| 特性 | 普通承诺 | 同态承诺 |
|-----|---------|---------|
| 运算 | ❌ | ✅ |
| 效率 | 一般 | 高 |
| 应用 | 简单 | 复杂协议 |

## 📚 总结

同态承诺 = VOLE + 标签转换
- 支持在承诺上运算
- 基于 GF(2^128) 标签
- 用于高效零知识证明
