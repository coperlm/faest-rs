### 2. 哈希比特向量

将比特向量映射到有限域向量：

```rust
pub fn hash_bitvector<F: SmallGF>(
    r: VectorView<F>,  // 随机点
    v: &GF2View        // 比特向量
) -> Vector<F> {
    // 计算：Σ v[i] * r^i
    let mut result = Vector::zeros(tau);
    let mut r_powers = r.to_owned();
    
    for (i, bit) in v.iter().enumerate() {
        if bit {
            result += &r_powers;
        }
        r_powers *= &r;  // 更新 r 的幂次
    }
    result
}
```

**用途**：将二进制数据转换为有限域元素。

### 3. 哈希矩阵

```rust
pub fn hash_matrix<F: SmallGF>(
    r: VectorView<F>,
    M: MatrixView<F>
) -> Matrix<F> {
    // 对每一行应用哈希
    M.axis_iter(Axis(0))
        .map(|row| hash_vector(r, row))
        .collect()
}
```

### 4. 比特乘累加

优化的批量计算：

```rust
// ys += x * bs  (逐比特)
pub fn bitmul_accumulate<F>(
    ys: &mut [F],    // 累加器
    x: F,            // 标量
    bs: &[u8]        // 比特数组
) {
    for (i, &byte) in bs.iter().enumerate() {
        for j in 0..8 {
            if (byte >> j) & 1 == 1 {
                ys[i * 8 + j] += x;
            }
        }
    }
}
```

## 💻 使用示例

### 示例1：哈希比特向量

```rust
use faest::arithmetic::hash_bitvector;
use faest::gf2::GF2Vector;
use faest::gf2psmall::GF2p8;
use ndarray::Array1;

// 随机点
let r = Array1::from_vec(vec![
    GF2p8(2), GF2p8(3), GF2p8(5)
]);

// 比特向量
let mut bits = GF2Vector::new();
bits.bits.extend([true, false, true]);  // [1, 0, 1]

// 计算哈希
let h = hash_bitvector(r.view(), &bits.bits);
// h = 1*r^0 + 0*r^1 + 1*r^2
//   = [GF2p8(1), GF2p8(1), GF2p8(1)]
//   + [GF2p8(4), GF2p8(9), GF2p8(25)]
```

unsafe fn simd_xor(a: &mut [u8], b: &[u8]) {

        let va = _mm256_loadu_si256(...);

### 批量处理

```rust
// 一次处理多个元素
pub fn batch_multiply(
    xs: &[F],
    ys: &[F]
) -> Vec<F> {
    xs.iter()
      .zip(ys.iter())
      .map(|(x, y)| *x * *y)
      .collect()
}
```
