# FAEST 项目概览

## 📚 什么是 FAEST？

**FAEST** = **F**ast **A**uthentication via **E**fficient **S**hort **T**ranscripts

这是一个**后量子数字签名方案**，意味着它可以抵抗未来量子计算机的攻击。

### 为什么需要后量子密码？
- 🔐 传统的 RSA、ECDSA 签名在量子计算机面前会被破解
- 🛡️ FAEST 基于对称密码学（AES），量子计算机难以攻破
- ⚡ 性能优秀，签名验证速度快

## 🎯 核心概念速览

### 1. **有限域（Finite Field）**
在特定规则下做加法和乘法的数学系统。
- **GF(2)**: 只有 0 和 1 的域（XOR 运算）
- **GF(2^8)**: 用于 AES 的 8 位字节域
- **GF(2^128)**: 用于高效计算的 128 位域

### 2. **VOLE（Vector Oblivious Linear Evaluation）**
一种让两方在不泄露私密信息的情况下共同计算的协议。

### 3. **零知识证明**
证明"我知道某个秘密"，但不泄露秘密本身。
FAEST 就是用这种技术来创建签名。

### 4. **Fiat-Shamir 变换**
将交互式证明转换为非交互式签名的技术。

## 🔄 签名流程（简化版）

```
1. 密钥生成 (keygen)
   生成 AES 密钥（私钥）和输入输出对（公钥）

2. 签名 (sign)
   ┌────────────────────────────────────────┐
   │ a. 使用 VOLE 协议生成承诺              │
   │ b. 通过 Fiat-Shamir 生成挑战          │
   │ c. 创建零知识证明                     │
   │ d. 输出签名                           │
   └────────────────────────────────────────┘

3. 验证 (verify)
   ┌────────────────────────────────────────┐
   │ a. 重新计算 Fiat-Shamir 挑战          │
   │ b. 验证零知识证明                     │
   │ c. 检查承诺的一致性                   │
   │ d. 返回验证结果                       │
   └────────────────────────────────────────┘
```

## 💡 关键术语表

| 术语 | 含义 | 在代码中的位置 |
|-----|------|-------------|
| **Field** | 有限域 | `field.rs`, `gf2*.rs` |
| **Prover** | 证明者（签名方） | `faest.rs` |
| **Verifier** | 验证者 | `faest.rs` |
| **Commitment** | 承诺 | `homcom.rs`, `veccom.rs` |
| **Challenge** | 挑战 | `fiat_shamir.rs` |
| **Response** | 响应 | `fiat_shamir.rs` |
| **Witness** | 见证（私密信息） | `aes.rs` |
