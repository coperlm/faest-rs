## 💻 第五步：编写你的第一个程序

创建文件 `my_first_faest.rs`:

```rust
use faest::aes::Aes;
use faest::fiat_shamir::{SignatureVerifier, Signer};
use faest::gf2psmall::GF2p8;
use faest::{keygen, FaestSignatureVerifier, FaestSigner};

fn main() {
    // 1. 生成密钥对
    let (secret_key, public_key) = keygen(Aes::Aes128);
    
    // 2. 准备消息
    let message = b"My first FAEST signature!";
    
    // 3. 签名
    let signer = FaestSigner::<GF2p8>::new(secret_key, public_key);
    let signature = signer.sign(message);
    
    // 4. 验证
    let verifier = FaestSignatureVerifier::<GF2p8>::new(Aes::Aes128, public_key);
    let is_valid = verifier.verify(&signature, message);
    
    println!("签名验证结果: {}", is_valid);
}
```

运行：
```bash
rustc --edition 2021 my_first_faest.rs -L target/debug/deps --extern faest=target/debug/libfaest.rlib
./my_first_faest
```

或者放到 `examples/` 目录：
```bash
mv my_first_faest.rs examples/
cargo run --example my_first_faest
```

## 🐛 常见问题

### Q1: 编译失败 "bincode" 错误
**A**: 已修复，如果还有问题，运行：
```bash
cargo update -p bincode
```

### Q2: 性能测试很慢
**A**: 确保使用 release 模式：
```bash
cargo bench --release
```

### Q3: CPU 不支持 AESNI/AVX2
**A**: 这个实现依赖硬件加速，需要支持的 CPU。
