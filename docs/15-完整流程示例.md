# 完整流程示例

## 🎯 从头到尾的签名验证

完整演示 FAEST 签名方案的使用。

## 📝 完整代码

```rust
use faest::aes::Aes;
use faest::fiat_shamir::{SignatureVerifier, Signer};
use faest::gf2psmall::GF2p8;
use faest::{keygen, FaestSignatureVerifier, FaestSigner};

fn main() {
    println!("=== FAEST 签名方案完整示例 ===\n");
    
    // ==================== 第一步：生成密钥对 ====================
    println!("1. 生成密钥对");
    let (secret_key, public_key) = keygen(Aes::Aes128);
    println!("   - 私钥: {:?}", secret_key);
    println!("   - 公钥输入: {:02X?}", public_key.input);
    println!("   - 公钥输出: {:02X?}\n", public_key.output);
    
    // ==================== 第二步：准备消息 ====================
    println!("2. 准备要签名的消息");
    let message = b"Hello, FAEST! This is a post-quantum signature.";
    println!("   消息: {}\n", String::from_utf8_lossy(message));
    
    // ==================== 第三步：创建签名 ====================
    println!("3. 创建签名");
    let signer = FaestSigner::<GF2p8>::new(secret_key, public_key);
    
    println!("   - 初始化签名者");
    println!("   - 计算扩展见证...");
    println!("   - 生成承诺...");
    println!("   - 应用 Fiat-Shamir 变换...");
    
    let signature = signer.sign(message);
    
    println!("   ✓ 签名完成");
    println!("   - 签名大小: {} 字节\n", signature.to_bytes().len());
    
    // ==================== 第四步：验证签名 ====================
    println!("4. 验证签名");
    let verifier = FaestSignatureVerifier::<GF2p8>::new(Aes::Aes128, public_key);
    
    println!("   - 初始化验证者");
    println!("   - 重新计算挑战...");
    println!("   - 检查一致性...");
    println!("   - 验证 AES 约束...");
    
    let is_valid = verifier.verify(&signature, message);
    
    if is_valid {
        println!("   ✓ 签名验证成功！\n");
    } else {
        println!("   ✗ 签名验证失败！\n");
        return;
    }
    
    // ==================== 第五步：测试篡改检测 ====================
    println!("5. 测试篡改检测");
    
    // 5.1 修改消息
    println!("   5.1 尝试修改消息...");
    let wrong_message = b"Hello, FAEST! This is a MODIFIED message.";
    let verifier2 = FaestSignatureVerifier::<GF2p8>::new(Aes::Aes128, public_key);
    let is_valid2 = verifier2.verify(&signature, wrong_message);
    
    if !is_valid2 {
        println!("       ✓ 正确拒绝了篡改的消息");
    } else {
        println!("       ✗ 错误接受了篡改的消息！");
    }
    
    // 5.2 修改签名
    println!("   5.2 尝试修改签名...");
    let mut corrupted_sig = signature.clone();
    // 修改签名的第一个字节
    // corrupted_sig.commitment[0] ^= 1;  // 具体修改方式取决于结构
    
    println!("       （签名结构受类型保护，无法直接篡改）\n");
    
    // ==================== 第六步：性能统计 ====================
    println!("6. 性能统计");
    
    use std::time::Instant;
    
    // 签名性能
    let start = Instant::now();
    let _ = signer.sign(message);
    let sign_time = start.elapsed();
    println!("   - 签名时间: {:?}", sign_time);
    
    // 验证性能
    let start = Instant::now();
    let _ = verifier.verify(&signature, message);
    let verify_time = start.elapsed();
    println!("   - 验证时间: {:?}", verify_time);
    
    println!("\n=== 示例完成 ===");
}
```

## 🔄 数据流

```
密钥生成:
  随机 → AES密钥 + 输入输出对

签名:
  消息 → 哈希 → 挑战 → 证明 → 签名

验证:
  签名 + 消息 → 重算挑战 → 检查证明 → 布尔值
```

## 📍 更多示例

### 批量签名

```rust
let messages = vec![b"msg1", b"msg2", b"msg3"];
let signatures: Vec<_> = messages
    .iter()
    .map(|msg| signer.sign(msg))
    .collect();
```

### 序列化

```rust
// 保存签名
let sig_bytes = signature.to_bytes();
std::fs::write("signature.bin", &sig_bytes)?;

// 加载签名
let sig_bytes = std::fs::read("signature.bin")?;
let signature = FaestSignature::from_bytes(&sig_bytes);
```

### 不同 AES 变体

```rust
// AES-192
let (sk, pk) = keygen(Aes::Aes192);
let signer = FaestSigner::<GF2p8>::new(sk, pk);

// AES-256
let (sk, pk) = keygen(Aes::Aes256);
let signer = FaestSigner::<GF2p8>::new(sk, pk);
```
