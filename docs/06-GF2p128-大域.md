# GF(2^128) - 大有限域

## 🎯 为什么需要 GF(2^128)？

GF(2^128) 有 2^128 个元素，主要用于：
1. **高效批量计算** - 一次操作处理更多数据
2. **嵌入小域** - 可以将多个 GF(2^8) 元素"打包"
3. **安全性** - 更大的域提供更强的安全保证

## 📐 基本表示

```rust
// 文件：src/gf2p128.rs

// 两种实现方式

// 1. 简单版本（两个 u64）
pub struct GF2p128Naive(pub [u64; 2]);

// 2. SIMD 优化版本（使用 CPU 指令）
pub struct GF2p128Fast(pub __m128i);  // 128位 SSE 寄存器

// 默认使用快速版本
pub type GF2p128 = GF2p128Fast;
```

## 🔢 元素表示

一个 GF(2^128) 元素 = 128 位：

```
高 64 位         低 64 位
[u64]           [u64]
或者
__m128i (SSE/AVX 寄存器)
```

## ⚙️ 加法（XOR）

```rust
impl Add for GF2p128Fast {
    fn add(self, other: Self) -> Self {
        unsafe {
            // 直接 XOR 两个 128 位值
            Self(_mm_xor_si128(self.0, other.0))
        }
    }
}
```

## ✖️ 乘法（使用 CLMUL）

使用 CPU 的 **CLMUL** 指令（Carryless Multiplication）：

```rust
fn mul(self, other: Self) -> Self {
    // 1. 无进位乘法
    let product = clmul(self, other);  // 256 位结果
    
    // 2. 模约简（对不可约多项式取模）
    let reduced = reduce(product);  // 128 位结果
    
    reduced
}
```

## 💻 使用示例

```rust
use faest::gf2p128::GF2p128;

let a = GF2p128::from_u128(0x123456789ABCDEF0);
let b = GF2p128::from_u128(0xFEDCBA9876543210);

// 加法
let sum = a + b;

// 乘法  
let product = a * b;

// 转回 u128
let value: u128 = sum.to_u128();
```

## 📊 性能优势

使用 SIMD 指令的优势：

| 操作 | 标量 | SIMD | 加速比 |
|-----|------|------|--------|
| 加法 | ~4周期 | ~1周期 | 4x |
| 乘法 | ~100周期 | ~10周期 | 10x |

## 📚 总结

- **大域** = 更多元素 = 更强安全性
- **SIMD** = 硬件加速 = 更快速度
- **嵌入** = 打包小域 = 批量处理
